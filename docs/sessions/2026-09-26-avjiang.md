## DB SCRIPTS — backup and migrate skip tenants whose database is absent

`src/script/db_backup.ts` and `src/db.ts updateAllTenantDatabases()` now read `information_schema.SCHEMATA` and
skip a tenant whose database doesn't exist on the target server, printing the skipped list; `--only` names that

lists 13 skipped; read-only `prisma migrate status` shows global (17) and both tenants (48) up to date.

**Why:** `global.tenant` lists 15 tenants but only 2 databases were migrated, so plain backup aborted and the
upgrade loop would have aimed `prisma migrate deploy` at missing databases. Deleting the 13 test tenant rows was

runbook §Phase 4 prep.
**Gotcha:** `prisma/global-client/schema.prisma` reads **`GLOBAL_DB_URL`**, not `TENANT_DATABASE_URL` — the

because the child process inherits the already-overridden `GLOBAL_DB_URL`. A manual `prisma migrate status`
for global with just `TENANT_DATABASE_URL` set silently checks the LOCAL database. Also: tonight's earlier docs
said "17 tenants / 15 test" — it's 15 / 13.
